# 演示前检查清单

> 目标：把「电脑/浏览器/隧道/登录态」这些外部依赖在开场前全部确认一遍，避免现场才发现。

## 一、电源与系统（演示前一天）

1. 笔记本插电，电源计划设为**不睡眠、不休眠**：

   ```powershell
   powercfg /change standby-timeout-ac 0
   powercfg /change hibernate-timeout-ac 0
   powercfg /change monitor-timeout-ac 15
   ```

2. 合盖行为设为「不采取任何操作」（控制面板 → 电源选项 → 选择关闭盖子的功能）。
3. 演示时段暂停 Windows 自动更新重启；关闭「快速启动」造成的异常关机风险。
4. 关闭会抢占焦点/弹窗的软件更新提醒（Edge、微信、输入法）。

## 二、启动顺序

1. 登录 Windows 后运行（或已由 `scripts/install_autostart.ps1` 注册为登录自启）：
   - `scripts/run_app.ps1`：后端 + Radicale，崩溃自动重启。
   - `scripts/run_bridge.ps1`：微信客服工作台桥接，崩溃自动重启。
2. 桥接会打开独立的 Edge 窗口：
   - **不要关闭、不要导航走**，登录态保存在 `data/kf_web_profile`。
   - 若日志提示「扫码登录」，用企业微信扫码，桥接会自动继续。
3. 手机 USB 连接电脑，执行：

   ```powershell
   tools\platform-tools-dl\platform-tools\adb.exe reverse tcp:8000 tcp:8000
   ```

4. 打开 DAVx5，点一次账户 `sdg` 的「同步」，确认日历里有最新事件。

## 三、预检（开场前 30 分钟）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\preflight.ps1
```

全部 `[OK]` 且输出 `== GO ==` 才开演。常见 `NO-GO`：

| 项目 | 处理 |
|---|---|
| `backend` | 后端没起：运行 `scripts/run_app.ps1` |
| `bridge-process` / `bridge-heartbeat` | 桥接没起或卡死：重启 `scripts/run_bridge.ps1` |
| `workbench-login` | 工作台掉登录：看桥接 Edge 窗口扫码 |
| `phone-usb` / `adb-reverse` | 重插 USB、重新执行 `adb reverse` |
| `davx5-calendar` / `calendar-events` | 检查 DAVx5 日历权限与同步 |
| `disk-space` | 清理磁盘或换盘 |

## 四、观众体验方式（已确定）

- **1–2 位观众上台**用手机扫码联系客服，其余观众看大屏。
- 同时只使用一个操作号；桥接自动跟随客服列表最上面的会话。
- **不支持 30 人同时自由扫码**：网页桥接一次只处理一个会话，多人并发会导致回复串台、OCR 排队、演示日历被污染。
- 多人想体验时，改用微信测试号通道（每个 openid 独立数据），或分批 3–5 人依次上台。

## 五、现场演示顺序（建议）

1. 发一段文字活动 → 卡片。
2. 转发一篇公众号文章 → 卡片。
3. 发一张活动海报截图 → OCR 卡片（首次 OCR 约 3–10 秒）。
4. `列表` → 分页/编号。
5. `改 N 时间`、`删 N` → 二次确认。
6. 发一条 2 分钟后开始的活动 → 在 DAVx5 点同步 → 等系统日历弹窗。

## 六、兜底方案

1. **桥接掉登录**：切到微信测试号通道继续演示文字/文章（不依赖浏览器自动化）。
2. **手机/隧道异常**：演示卡片、列表、改删与 Radicale 中的事件，系统通知改用录屏。
3. **电脑异常**：播放提前录好的 3–5 分钟完整流程视频。
4. 所有演示数据（#1/#2/#3/#10）已存在，可随时用 `列表` 恢复现场。

## 七、已知限制（评委问答可用）

- 桥接是**网页工作台自动化**，不是官方客服消息 API；依赖登录态与页面结构，属于演示级方案。
- 微信客服限制：客户回复前最多主动发 5 条消息；桥接按「一条客户消息一条回复」工作。
- 本机方案依赖 USB + `adb reverse`；拔线或 adb 重启后需重做。
- 所有服务运行在演示电脑上，**电脑关机即停止**；没有云端部署。
- 网页桥接单会话处理，不支持大量观众同时接入；正式产品应改用微信客服官方 API（`sync_msg/send_msg`），本次因可信 IP/回调配置限制采用网页桥接。
