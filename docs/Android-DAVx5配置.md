# Android 系统日历配置（DAVx5 + CalDAV）

> 这是**演示机**的一次性配置，约 5–10 分钟。观众不需要做这一步；他们只在微信里体验。
>
> 公网地址会随隧道重启变化。当前地址见项目根目录 `data/public_url.txt`，或向演示负责人确认。

## 0. 已验证的本机方案（零预算，推荐）

不依赖公网隧道，手机通过 USB + adb 反向隧道直连电脑上的后端：

```powershell
# 每次拔线、adb 重启、电脑重启后都要执行
adb reverse tcp:8000 tcp:8000
adb reverse --list          # 应看到 UsbFfs tcp:8000 tcp:8000
```

手机端 DAVx5 填：

| 项目 | 值 |
|---|---|
| URL | `http://127.0.0.1:8000/radicale/` |
| 用户名 | `sdg` |
| 密码 | `.env` 的 `CALDAV_PASSWORD` |

注意：

- 首次添加账户时 DAVx5 会申请**日历权限**，必须允许（设置 → 应用管理 → DAVx5 → 权限 → 日历）。权限被拒时账户能建出来，但不会生成本地日历、同步也不会发请求。
- 同步成功后可看到日历 `sdg/calendar`（Radicale 集合名）。在系统日历里勾选它。
- 演示前在 DAVx5 账户页点一次「同步」；平时 DAVx5 按系统同步间隔自动拉取。
- 2026-11-25 已在 Redmi Note 11 Pro+ / Android 13 上验证：事件进入系统日历，并在开始时刻弹出「提醒测试 / 上午9:53, 309会议室」通知。

## 1. 准备信息（公网隧道方案）

| 项目 | 值 |
|---|---|
| CalDAV 地址 | `https://<当前公网地址>/radicale/` |
| 备用地址 | `https://<当前公网地址>/radicale/sdg/` |
| 用户名 | `sdg` |
| 密码 | 向演示负责人获取，不通过微信发送 |

## 2. 安装 DAVx5

- Google Play 搜索 **DAVx5**（包名 `at.bitfire.davdroid`）
- 或 F-Droid
- 国内无法访问 Play 时，从 DAVx5 官网下载 APK

## 3. 添加账户

1. 打开 DAVx5 → 右下角 **+**
2. 选择 **使用 URL 和用户名登录**（Login with URL and user name）
3. 填写：
   - 基础 URL：`https://<当前公网地址>/radicale/`
   - 用户名：`sdg`
   - 密码：见上
4. 点 **登录**。DAVx5 会发现 principal 与日历集合。
5. 如果发现不到日历，把 URL 改成 `https://<当前公网地址>/radicale/sdg/` 再试。
6. 在账户页勾选 `sdg/calendar` 日历（早期文档写作「日程Agent」），开启同步。

## 4. 系统日历设置

1. 打开手机自带「日历」App
2. 设置 → 日历显示 → 勾选 DAVx5 账户下的「日程Agent」
3. 设置 → 通知 → 允许日历通知；关闭对该日历的「免打扰」
4. 如果系统日历有「默认提醒」，不要覆盖 DAVx5 事件自带的 VALARM

## 5. 防止 Android 杀后台（关键）

不同厂商路径不同，原则是让 **DAVx5 与日历 App 都不被省电策略限制**：

| 厂商 | 操作 |
|---|---|
| 小米 / HyperOS | 设置 → 应用 → DAVx5 → 省电策略 → 无限制；自启动打开；后台弹出界面允许 |
| 华为 / HarmonyOS | 应用启动管理 → DAVx5 → 手动管理，允许自启动/关联启动/后台活动 |
| OPPO / ColorOS | 电池 → 应用耗电管理 → DAVx5 → 允许后台运行；自启动允许 |
| vivo / OriginOS | 电池 → 后台耗电管理 → DAVx5 → 允许后台高耗电；自启动允许 |
| 三星 / One UI | 电池 → 后台使用限制 → 从「休眠应用」中移除 DAVx5 |
| Pixel / 原生 | 电池 → 无限制；关闭「自适应电池」对 DAVx5 的限制 |

另外：关闭系统的「深度睡眠 / 超级省电」对 DAVx5 的影响；演示前手动打开一次 DAVx5 并点「立即同步」。

## 6. 验证

1. 在微信里给测试号发：`配置完成`
2. 服务端会写入一条 **2 分钟后**的「系统日历测试」事件，并立即同步
3. 在 DAVx5 里点一次「立即同步」
4. 打开系统日历，确认事件出现
5. 等待 2 分钟，确认系统通知弹出
6. 飞行模式 + 微信强行停止，再等一条 2 分钟测试事件，确认仍能弹窗

## 7. 常见问题

| 现象 | 排查 |
|---|---|
| DAVx5 登录 401 | 密码错误；或 URL 少了 `/radicale/` |
| 登录成功但没有日历 | 先确认 DAVx5 日历权限已允许；URL 改成 `.../radicale/sdg/`；确认服务端集合 `sdg/calendar` 存在 |
| 事件不出现 | DAVx5 里点「立即同步」；检查是否勾选了 `sdg/calendar`；检查 `adb reverse --list` 是否还有映射 |
| 事件出现但不提醒 | 日历通知权限、免打扰、电池限制；检查系统日历是否勾选该账户 |
| 提醒时间不对 | 时区必须是 Asia/Shanghai；不要用 VPN 改变系统时区 |
| 隧道重启后不同步 | 公网地址变了（改 DAVx5 URL 与微信后台回调）；本机方案则重新执行 `adb reverse tcp:8000 tcp:8000` |

## 8. 演示建议

- 演示前 30 分钟完成配置，并跑一次 `配置完成` 验证弹窗。
- 预置 #1/#2 两条冲突活动；现场用 `同步` 展示写入。
- 观众只扫码体验微信内卡片/列表/改删；不要让他们配置 DAVx5。
- 准备录屏兜底：系统日历下拉 + 到点弹窗。
