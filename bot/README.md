# 个人微信机器人（备用号）可行性验证

> 风险提示：Windows hook 方案违反微信协议，可能导致**备用号封号**。只用备用号，不要用主号或比赛账号。验证不通过就停止，回到服务号 + 复制链接入口。

## 版本组合

- 微信 Windows：**3.9.12.51**（当前电脑是 4.2.0.13，不支持 hook）
- wcferry：**39.5.2.0**
- Python：项目 `.venv-bot`（单独环境）

## 验证步骤

1. 安装 `tools/wechat-3.9.12.51/WeChatSetup-3.9.12.51.exe`（先验证数字签名）。
2. 关闭电脑上正在运行的微信 4.x；用**备用号**登录 3.9.12.51。
3. 主号加备用号为好友。
4. 运行探针（建议以管理员身份）：

   ```powershell
   .venv-bot\Scripts\python.exe bot\wcf_probe.py
   ```

5. 主号转发一篇公众号文章给备用号；探针应打印 `type=49` 且内容里含文章 URL。

## 通过后

再实现 `bot/bridge.py` 与后端 `/bot/ingest`、`/bot/command`，复用现有文章解析、指令和日历同步。

## 失败回退

- hook 注入失败、版本不匹配、杀毒拦截、封号风险 → 立即停止，继续使用测试号 + 复制链接粘贴。
